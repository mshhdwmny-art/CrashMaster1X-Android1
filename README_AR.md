# CRASH MASTER 1X — مشروع جديد ونظيف

الإصدار الأول يتضمن تطبيق Android، نافذة عائمة، إدخال المضاعفات يدوياً، وحساب عدد النتائج والمتوسط وآخر نتيجة.

## البناء من الهاتف عبر GitHub
1. أنشئ مستودعاً جديداً باسم `CrashMaster1X-Android`.
2. ارفع محتويات هذه الحزمة إلى جذر المستودع، بما فيها المجلد المخفي `.github`.
3. افتح تبويب Actions وشغّل `Build Crash Master APK`.
4. بعد نجاح المهمة نزّل Artifact باسم `CrashMaster1X-debug-apk`.

## المرحلة التالية
إضافة قراءة الشاشة بموافقة المستخدم وحفظ سجل الجولات، بعد بناء واختبار النسخة الأساسية.

## تنبيه
التطبيق أداة إحصائية فقط؛ لا يتنبأ بنتيجة الجولة القادمة، ولا يضع رهانات، ولا يضمن الربح. لا تشارك كلمة مرور منصة المراهنات.
